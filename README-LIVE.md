# يلا كورة — النسخة الحية

هذه النسخة تستخدم API-Football عبر `server.js` حتى يبقى مفتاح API مخفياً عن المتصفح.

## إعداد المفتاح

لا تضع المفتاح داخل `index.html`.

على أي استضافة Node/Express أضف متغير البيئة:

`API_FOOTBALL_KEY=ضع_مفتاحك_هنا`

ثم شغّل:

`npm install`

`npm start`

## الوظائف الموصولة

- مباريات حقيقية حسب أمس/اليوم/غداً.
- النتائج والحالات الحقيقية.
- مباريات مباشرة عبر `/api/live`.
- تفاصيل المباراة والأحداث والتشكيلات والإحصائيات عندما يوفرها API-Football.
- بيانات الفريق الحقيقية.
- الترتيب والهدافون.
- يعمل على توقيت بغداد.
- الواجهة الحالية لم يتم إعادة بنائها.

## ملاحظة الخطة المجانية

المفتاح يجب أن يبقى سرياً، والخطة المجانية لـ API-Football لها حد يومي؛ لذلك تم وضع تخزين مؤقت وتحديث مباشر دوري لتقليل استهلاك الطلبات.
