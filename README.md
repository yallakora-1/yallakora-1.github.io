# يلا كورة

Node.js + Express backend for Yalla Kora.

## Render
- Language: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Plan: Free

## Environment
Add `API_FOOTBALL_KEY` in Render Environment Variables. Never commit the real key to GitHub.

The backend proxies selected API-Football endpoints and caches responses in memory to reduce quota usage.
